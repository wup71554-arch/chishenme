# 今天吃什么

选好这一餐、口味和忌口，点一下，随机给你一个合理的搭配。

纯静态网页，**没有后端、不联网、不花钱**。所有偏好存在浏览器本地，不会上传到任何地方。

## 怎么用

双击 `index.html` 就能打开。想分享给别人，把整个文件夹发过去，或者按下面部署到 GitHub Pages。

## 部署到 GitHub Pages

1. 在 GitHub 上新建一个仓库（Public），名字随意，比如 `chishenme`
2. 把本文件夹里的文件推上去
3. 仓库页面 → Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存
4. 等一两分钟，访问 `https://你的用户名.github.io/chishenme/`

## 想加菜？

改 `data.js` 就行，照着现有的格式加一行：

```js
{ name: "菜名", meals: ["lunch", "dinner"], taste: ["家常"], contains: ["辣"], meat: true }
```

| 字段 | 说明 |
|---|---|
| `name` | 菜名 |
| `meals` | 适合哪几餐：`breakfast` / `lunch` / `dinner`，可以多个 |
| `taste` | 口味标签：`清淡` / `家常` / `辣` / `重口` / `酸甜` |
| `contains` | 含有哪些忌口成分，用户勾了就会被过滤掉。可选值见 `data.js` 底部的 `AVOIDS` |
| `meat` | 是否荤菜。吃素的人会自动跳过。**不写就是素菜** |

四个分类：`staples` 主食、`proteins` 主菜、`veggies` 蔬菜、`soups` 汤。
早餐不配汤，所以汤不用标 `breakfast`。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `style.css` | 样式（跟随系统深色模式） |
| `data.js` | 食物库 + 可选项，**要加菜改这个** |
| `app.js` | 筛选和随机逻辑 |

## 关于搭配

搭配是从固定食物库里随机抽的（主食 + 主菜 + 蔬菜 + 汤），只保证**不踩忌口、不连着重复**，
并不是营养学意义上的均衡计算。当个"帮你做决定"的工具用就好，别当营养处方。
